# 本机 AICost 文案与配图

读取 Story Studio 运行配置里的 Python 可执行文件。用该解释器调用 `<技能目录>/scripts/aicost_client.py`。文案和图片使用各自授权的凭据，本机账户可解密。`check` 只核对四个模型对相应凭据可见。

## 文案

当写作阶段开启时，先按对应写作模块收集事实、时间线和来源。把核实材料、写作风格、字数、定稿要求和必须保留的事实整理为本期提示词，调用 `text` 生成口播稿、选题或改稿。文案主模型与备用模型依照本机设置。核对返回的字数、史实和来源，不能把模型补充的引文当作核实材料。涉及实质性返工时，再用同一路由提交修订提示词。若两模型都失败，说明失败原因并保留本期提示词。

```text
<运行时Python> <技能目录>/scripts/aicost_client.py text --prompt-file <本期提示词> --output <输出文案.md>
```

## 配图

只有实际生图阶段才调用 `image`。按配图模块整理提示词、画幅和参考图，使用不同 `--reference` 参数传入每张本期已确认的本地参考图。正文画幅缺省用 864×1536。其他尺寸按 AICost 图片接口文档与本期画幅选择。输出路径指定为新的 `.png` 文件，按镜号命名。出图后按原配图模块检查人物、画风、时代和裁切。

```text
<运行时Python> <技能目录>/scripts/aicost_client.py image --prompt-file <单镜提示词> --output <shot-01.png> --size 864x1536 --reference <参考图.png>
```

如果返回 `pending`，保留任务回执和输入，之后使用相同命令查询已有任务。服务确认任务失败后，按错误类型决定重试或切换。`submission_unconfirmed` 表示未获得确切提交结果，先核对该请求的状态再继续。文案、图片只使用用户指定的主备模型。

文案请求等待上限按 420 秒处理，覆盖 AICost 已出现的 164–398 秒服务端任务耗时，不能在 90 秒时把已提交任务误判为失败。确定模型不可用、模型报错时直接切备用。限流、过载或服务暂时不可用时，等待 3 秒以后用当前模型再试一次，仍失败才切备用。鉴权、余额、内容审核或请求参数错误直接说明原因。保留实际返回的模型与尝试结果。
